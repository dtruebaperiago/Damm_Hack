# Limitar el codi de participació a una sèrie de seguiment

Cada sèrie correspon al seguiment d’un canvi o iniciativa i té els seus propis codis de participació. Vam considerar un codi reutilitzable per a totes les enquestes, però el codi per sèrie permet comparar respostes al llarg d’un canvi i limita els vincles entre consultes sobre iniciatives diferents. El servidor calcula els canvis de les respostes aparellades i RRHH en veu els agregats.
